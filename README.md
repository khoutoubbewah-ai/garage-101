# Garage 101

An interactive, safety-first car-maintenance course for beginners. Rotate the illustrated vehicle, select a maintenance hotspot, and work through practical lessons for common roadside and driveway tasks.

## Live app

**[Open Garage 101](https://garage-101-indy.khoutoubbewah.chatgpt.site)**

The hosted app is currently private and uses ChatGPT sign-in.

## Course stations

- Battery identification and safe jump-starting order
- Oil level, dipstick, filter, and oil-change fundamentals
- Tires, lug nuts, approved lift points, and jack safety
- Wiper-blade replacement
- Engine air-filter replacement
- Coolant checks and overheating precautions
- Exterior lights and signals

The app also includes saved practice progress, roadside-ready checklists, and Indianapolis seasonal reminders for cold batteries, potholes, heat, and road salt.

## Run locally

No build step or package installation is required.

1. Serve the `dist` directory with any static web server.
2. Open the local address in a modern browser.

For example:

```sh
python3 -m http.server 4173 --directory dist
```

Then visit `http://localhost:4173`.

## Important safety note

This project provides general educational guidance. The vehicle owner's manual, warning labels, specified lift points, fluid requirements, torque values, and manufacturer procedures always take precedence. Stop and seek qualified help whenever a vehicle cannot be secured or a procedure is unclear.
